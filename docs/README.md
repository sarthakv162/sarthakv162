# Sarthak Verma — Portfolio

Responsive dark editorial portfolio focused on AI/ML engineering, applied research, multimodal systems, and intelligent agents.

## Preview locally

This is a static site. From the repository root:

```bash
python -m http.server 8000 --directory docs
```

Open http://localhost:8000.

## Enable GitHub Pages

The site files live in `docs/` so the existing profile README at the repository root is left untouched.

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/docs**.
4. Save. GitHub Pages will publish the site at:

   https://sarthakv162.github.io/sarthakv162/
